# LegalConvert Landing

Landing page demostrativa orientada a conversión para un estudio jurídico argentino. Proyecto creado como pieza de portfolio para mostrar diseño web responsive, estructura de captación de leads y preparación para campañas digitales.

## Objetivo

Construir una landing profesional, clara y rápida que pueda adaptarse a campañas de Google Ads o Meta Ads, con foco en experiencia móvil y generación de consultas.

## Incluye

- Hero con propuesta de valor y CTA principal.
- Secciones para derecho laboral y civil.
- Presentación del estudio y profesionales ficticios.
- Proceso de atención.
- Preguntas frecuentes.
- Formulario con validación en JavaScript.
- Página de agradecimiento para simular seguimiento de conversiones.
- Navegación responsive y menú móvil.
- Animaciones suaves respetando `prefers-reduced-motion`.
- Estructura semántica y accesible.

## Tecnologías

- HTML5
- CSS3
- JavaScript vanilla
- Diseño responsive / mobile-first

## Nota de portfolio

`Estudio Legal Nova`, sus profesionales y todo el contenido comercial de esta demo son ficticios. El proyecto no representa a un cliente real ni recibe consultas jurídicas reales.
